# Treningsapp

Personlig treningsapp (PWA). Brukeren snakker norsk – svar kort og konkret på norsk.

- SPEC.md er kravene og arbeidsmåten. Følg den nøyaktig; ikke finn på egne treningsregler.
- PLAN.md er Claudes forslag (arkitektur, mappestruktur, datamodell) og åpne spørsmål.
  Start med å få svar på spørsmålene i PLAN.md som ikke er besvart, før du bygger.
- Bygg i milepælene i SPEC.md seksjon 14. Etter hver milepæl: kjør tester og build,
  si kort hva brukeren kan teste.
- Oppdater PLAN.md med avgjørelser underveis, så alt følger med prosjektmappa.
